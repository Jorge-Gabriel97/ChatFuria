# 🤖 ChatFuria

ChatFuria é um chatbot web simples e funcional, construído com HTML, CSS e JavaScript, projetado para oferecer uma interface amigável de conversação. Ele simula interações com um assistente virtual de maneira leve, responsiva e rápida.

## 🔗 Acesse o site

👉 [chatbotf.netlify.app](https://chatbotf.netlify.app/)

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6)

## 📁 Estrutura do Projeto
├── index.html # Página principal
├── css/
│ └── style.css # Estilos da interface
├── js/
│ └── main.js # Lógica do chatbot


## ⚙️ Funcionalidades

- Interface limpa e intuitiva
- Simulação de respostas automatizadas
- Comportamento de digitação e scroll automático
- Interface responsiva

## 🚀 Como utilizar localmente

# Clone o repositório
git clone https://github.com/Jorge-Gabriel97/ChatFuria.git

# Acesse a pasta do projeto
cd ChatFuria

# Abra o index.html no seu navegador
